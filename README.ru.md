# TeamSpeak Audio Control

[English](README.md) | **Русский**

Приложение для управления звуком трансляции в **TeamSpeak 6** на Windows.
Позволяет выбирать, какие приложения слышны в трансляции, и отдельно настраивать их громкость.
Системная громкость приложений не меняется.

[Скачать для Windows](https://github.com/gutjei/ts6-audio-control/releases/latest)

## Возможности

- Выбор приложений для захвата звука.
- Громкость каждого приложения от 0 до 200%. Двойной клик по шкале возвращает 100%.
- Автоматические правила включения и исключения приложений.
- Автоподключение к TeamSpeak, запуск вместе с Windows и работа в трее.
- Подключение перед началом трансляции; уже запущенную трансляцию нужно перезапустить.
- Светлая и тёмная темы, сохранение настроек.

## Как это работает

Приложение загружает в TeamSpeak небольшую нативную DLL. MinHook перехватывает создание
захвата звука из TeamSpeak.dll, а C++-обёртки аудиоинтерфейсов подключают микшер.
Команды передаются через локальный именованный канал Windows; аудиоданные остаются
в C++. Тихий фоновый процесс также написан на C++. Frida и JavaScript-движок
в рабочую сборку не входят. Панель пока использует Python и Qt Widgets.
Файлы TeamSpeak на диске не изменяются.

Подключите панель **до начала трансляции**. Нативная версия не обнаруживает поток,
созданный до подключения: такую трансляцию нужно перезапустить. После отключения
панели управляемый поток становится тихим; для возврата обычного захвата перезапустите
трансляцию. Потеря heartbeat также заглушает управляемый поток. Новые трансляции,
созданные при отключённой панели, используют обычный захват TeamSpeak.

Одновременно разрешено одно подключение панели. После обновления нативной DLL
или экспериментов с Frida перезапустите TeamSpeak. Инструкции сборки и проверки
приведены в [английском README](README.md#building).

Неофициальный проект, не связанный с разработчиками TeamSpeak.
